変更点

ディレクトリ構造を src/ 配下に移行（git mv で履歴保持）

src/
  app/
    layout.tsx      # ヘッダー/フッターを合成、メタデータ、フォント
    page.tsx        # トップページ（Server Component）
    loading.tsx     # 追加（必須ファイル）
    error.tsx       # 追加（"use client" のエラーバウンダリ）
    globals.css
  components/        # UI コンポーネントを分離
    site-header.tsx
    site-footer.tsx
    section-heading.tsx
    book-card.tsx
  lib/
    shop-data.ts     # 店舗情報・書籍・ジャンル・ニュースの取得関数（DB 化時の差し替え口）
  types/
    index.ts         # Book / Genre / NewsItem / NavItem 型

- tsconfig.json: パスエイリアスを @/* → ./src/* に更新
- コンポーネントはすべて Server Component。error.tsx のみインタラクション（reset）が必要なため "use client"
- any 不使用（型は src/types に集約）、Tailwind v4 は globals.css の @theme のみ、next lint ではなく eslint を直接実行

今回適用していない規約（該当機能がないため）

- Prisma 7 / Zod / Server Actions — データ永続化・フォーム送信がないため未導入。src/lib/shop-data.ts の関数を Prisma 取得に差し替える設計にしてあります
- shadcn/ui — 必要なコンポーネントが少なく未導入（使う場合は CLI で追加）
- "use cache" + cacheLife() — 現状トップページは請求時データなしで完全に静的プリレンダリング（○ Static）されており、use cache は cacheComponents の有効化が前提になります。shop-data.ts を実 DB アクセスにする段階で、その取得関数に "use cache" / cacheTag() を付けるのが規約どおりの置き場所です
